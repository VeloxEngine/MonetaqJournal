# Monetaq Journal

A high-performance technical engineering publication built with pure HTML5, vanilla CSS, and vanilla JavaScript. Features a strict dark minimalist aesthetic, Apple-inspired typography, hairline borders, and zero frontend framework dependencies.

## 🚀 Live Demo & Structure

- **Homepage (`index.html`)**: Features real-time client-side search, tag-based filtering, and dynamic article cards.
- **Design System (`css/style.css`)**: Dark obsidian surface palette, translucent frosted glass overlays, and typography tracking rules.
- **Vanilla Logic (`js/main.js`)**: Reading progress bar, category filter pills, instant search filtering, code block copy triggers, and mobile drawer.
- **Articles (`posts/`)**: 10 production-ready technical guides (minimum 500+ words each) covering Next.js, Supabase, Cloudflare, database architecture, and edge computing.
- **Legal Compliance**: Comprehensive `privacy.html`, `terms.html`, and `disclaimer.html`.

## 🛠 Local Development

```bash
# Install local dependencies
npm install

# Start development server on http://localhost:3000
npm run dev
```
